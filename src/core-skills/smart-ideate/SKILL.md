# Ideate

## Purpose

Provide a renamed compatibility entrypoint for brainstorming and early option generation.

## Backing Skill

This mode is a renamed compatibility layer over `skill:smart-brainstorming`.

## Shortcut Deck

- `A` -> show all ideation techniques
- `C` -> challenge the leading concept
- `R` -> reshuffle methods
- `Z` -> finish with the chosen shortlist

## Output Contract

Return:

1. `Prompt`
2. `Technique`
3. `Ideas`
4. `Shortlist`
5. `Recommended Next Command`
